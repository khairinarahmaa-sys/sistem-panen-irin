Proyek ini merupakan aplikasi sederhana berbasis Python yang dirancang untuk membantu pencatatan data hasil panen pertanian serta perhitungan otomatis pendapatan dan diskon komoditas agroindustri.

## Fitur Utama
1. Pencatatan data komoditas dan berat hasil panen
2. Perhitungan total pendapatan awal
3. Perhitungan pemotongan diskon khusus penjualan komoditas

## Cara Menjalankan Program
1. Pastikan Python 3 sudah terinstal pada komputer Anda
2. Buka terminal atau command prompt lalu masuk ke direktori proyek
3. Jalankan program dengan perintah berikut
   python sistem_panen.py
